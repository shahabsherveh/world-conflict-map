# Portfolio material

Everything needed to present **Global Conflict Map** to a recruiter, a reviewer, or an
interviewer. Nothing here is part of the shipped app; it is marketing and preparation
material that lives alongside the code.

## Files

| File | What it is for |
|---|---|
| `cv.md` | CV bullets, where to place them, and how to tailor them to a role |
| `github-copy.md` | The GitHub "About" blurb, one-line tagline, and topic tags |
| `readme-sections.md` | Copy-and-paste sections for `README.md` (TL;DR, How it works, Why I built this) |
| `interview-prep.md` | The five questions an interviewer will most likely ask, with answers |

## How to use it

- **Before applying:** copy the bullets from `cv.md` into your CV and fill in the
  "Why I built this" paragraph in `readme-sections.md` with your own motivation.
- **Before posting the repo:** apply `github-copy.md` (About field + topics) and add a
  screenshot to the top of `README.md`.
- **Before an interview:** read `interview-prep.md` out loud once. The numbers
  (~57k events/day, 100 km, 14 days, 0.03 s/event) and the failure stories are what
  separate this project from a tutorial.

The content overlaps on purpose: the tagline in `github-copy.md`, the TL;DR in
`readme-sections.md`, and the first answer in `interview-prep.md` are three lengths of
the same pitch. Pick whichever fits the moment.
