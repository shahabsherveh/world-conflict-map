# GitHub copy

## "About" field

GitHub truncates the About field around 150 characters on repo cards. This fits cleanly:

> Live map of armed conflicts worldwide, built from GDELT news data with ML filtering.
> Self-updating, browsable across time.

(139 characters.)

## One-line tagline

For a portfolio site header, LinkedIn project entry, or the repo `description`:

> An armed-conflict map that ingests ~57k news events a day, filters them with a
> zero-shot model, and groups them into browsable conflicts.

## Screenshot

A repo with a map screenshot gets dramatically more attention than one without. A
single frame showing the cluster heatmap plus the side panel is enough. Put it directly
under the README's opening paragraph.

to the repo.
